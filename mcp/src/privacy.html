Privacy policy — Loom MCP

Last updated: September 25, 2026

This policy covers the MCP server at loom-mcp.mhsenkow.workers.dev and related demo pages. The Loom app at loom.ibm.io and the desktop app keep data local unless you explicitly load remote open-data sources.

MCP server

  • CSV, JSON samples, or column schemas are sent only when you (or an AI assistant on your behalf) call a Loom tool.
  • Payloads are profiled and turned into chart recommendations / Vega-Lite specs in memory.
  • Data is not stored, logged as draft content, or used for training.
  • Request size is capped (~400 KB / 500 rows) and truncated if larger.
  • No accounts are required for the authless MCP endpoint.

Loom web & desktop

  • Desktop Loom keeps DuckDB and files on your machine.
  • The web UI at loom.ibm.io runs in your browser; optional catalog proxies fetch public open-data listings.
